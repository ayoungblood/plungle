# [docs](../index.md)/[radios](../radios.md)/cpeditor_radioddity

`cpeditor_radioddity` supports parsing and generation of JSON files compatible with the excellent [Codeplug Editor](https://www.cpeditor.co.uk/) by David MM7DBT.

This driver targets Codeplug Editor Radioddity Version 0.5.0405.1, and is tested with the Radioddity DB25-D radio.

## Properties/Specifications

Based on Codeplug Editor Radioddity Version 0.5.0405.1 and [DB25-D specifications](https://www.radioddity.com/products/radioddity-db25d).

* TX Frequencies: 136 - 174 MHz, 400 - 480 MHz
* Supported modes: FM, NFM, DMR
* Max channels: 4000 - zones
* Max channel name length: ??
* Max zones: 4000 - channels
* Max zone name length: ??
* Max channels per zone: ??
* Max scanlists: ??
* Max scanlist name length: ??
* Max channels per scanlist: ??
* Max talkgroups: 2000
* Max talkgroup name length: ??
* Max talkgroup lists: ??
* Max talkgroups per talkgroup list: ??
* Max DMR IDs: 1
* Max DMR ID name length: ??

## CPS file format notes

Codeplug Editor saves a JSON file.
